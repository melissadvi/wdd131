Site Name

Web of Versions

The name combines the idea of a web with the different versions of the same hero across film universes. It is short, easy to remember and tells visitors that the site connects and compares those versions.

Optional domain availability:web-of-versions.org

Site Purpose

Web of Versions is an informational fan guide that helps visitors understand the different Spider-Man movie versions. The site provides:

  • A home page that introduces the character and the film universes.
  • A movies page with an interactive table that can be filtered by universe or actor and sorted by release year.
  • A way to mark movies as watched, saved in the browser.
  • A villains page that shows the enemies of each version.
  • A contact page with a form for fan polls.
  • A references page that credits all sources.

Scenarios

Questions a typical visitor would ask, which the site content must answer:

  1. Which Spider-Man movie should I watch first?
  2. What is the difference between each version of the character?
  3. Which movies has this actor appeared in?
  4. Which movies have I already watched?
  5. Which villains appear in each universe?

Typography

Two fonts from Google Fonts, each with a generic fallback.

Oswald (sans-serif), 700
Used for the site name and all headings. Example: One Hero, Many Versions
Open Sans (sans-serif), 400 and 600
Used for body text, navigation, tables, forms and buttons. Example: Filter the movies by universe or actor.
